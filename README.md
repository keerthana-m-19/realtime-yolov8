# Real-Time Object Detection using YOLOv8

## Overview

This project implements real-time object detection using YOLOv8 and OpenCV. The system captures live video from a webcam, detects objects in real time, and displays bounding boxes, class labels, and confidence scores on the video stream.

## Features

* Real-time object detection using YOLOv8
* Live webcam video processing
* Bounding box visualization with labels and confidence scores
* FPS monitoring for performance evaluation
* Support for custom-trained YOLO models

## Technologies Used

* Python
* OpenCV
* Ultralytics YOLOv8
* NumPy

## Project Workflow

1. Capture video frames from webcam
2. Process frames using YOLOv8
3. Detect and classify objects
4. Draw bounding boxes and labels
5. Display results in real time

## Results

* Successfully detected multiple objects in real-time video streams.
* Achieved accurate object localization and classification.
* Demonstrated practical application of Computer Vision and Deep Learning techniques.
